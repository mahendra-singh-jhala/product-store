# 🛒 E-Commerce Product Store

A modern, responsive e-commerce product store built with **React** and styled using **Tailwind CSS**. This app allows users to browse products fetched from an API, add them to a shopping cart, adjust quantities, and see real-time pricing updates.

## ✨ Features

- 🛍️ Browse products dynamically fetched from an API
- 🛒 Add products to a shopping cart
- 🔄 Increase or decrease item quantities in the cart
- ❌ Remove items from the cart
- 💵 View automatically updated total prices
- 📱 Fully responsive design for mobile, tablet, and desktop
- 🎨 Clean and modern UI using Tailwind CSS

## 🚀 Technologies Used

### Frontend
- React.js
- React Router
- Axios
- Tailwind CSS

  
### Installation

1. **Clone the repository:**

```bash
 git clone https://github.com/mahendra-singh-jhala/product-store
```

2. **Install dependencies**

```bash
 npm install
```

3. **Run the frontend**

```bash
 npm start
```
